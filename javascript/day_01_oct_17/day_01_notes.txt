Web Development
===============
-Developing Websites  (https://www.amazon.in/   https://www.zomato.com/ )


1. FrontEnd : User Interface - Presentation Layer 
        HTML : Content ( div, para, button, inputbox, dropdown, form )
        CSS : Styling ( Color, background , margin, padding )
        Bootstrap : CSS Library ( pre-defined css classes)
        Javascript : Behavior of a webpage, dynamic content, Interactivity
        React/Angular/Vue : Javascript frameworks ( RAD , CLI , build, deploy )

2. BackEnd :  Business Layer
              Build REST APIs (https://fakestoreapi.com/products)
              java / .net / python / PHP / Go

3. DataBase : Holds the Application Data
