Modules
=======
-Modules allow us to split our code into separate files, each focusing on a specific feature.
-Easier to maintain, Reusable 

-2 Module Systems   
	a. CommonJS Module System      (module.exports , require())
	b. ECMASCRIPT Module System    (export , import)


ESM imports & exports
=====================
-Default import:
  import DefaultMember from 'src/my_lib';
-Named imports:
  import { name1, name2 } from 'src/my_lib';
-Combining a default import with named imports
  import DefaultMember, { name1, name2 } from 'src/my_lib';
  import React, { Component } from 'react';


Named Export vs Default Export
==============================
-Only one default export is allowed per file,where as multiple named exports are allowed per file.
-Named exports are useful to export several values. 
-A default export can be a function, a class, an object(cann't be variables). 
 This value is to be considered as the “main” exported value since it will be the simplest to import
-The name of imported module has to be the same as the name of the exported module for named exports.
-The naming of import is completely independent in default export and we can use any name we like.
ex: import MyReact, { MyComponent } from "react";
           correct    wrong-namedExport



Dynamic Import
==============
-A Dynamic import allows us to import a module at runtime instead of at the top of the file.
-Module is loaded only when needed
-Improve the performance


Static Import
	import mathObj from "./math.js";  

Dynamic Import:
	const mathObj = await import('./math.js')



object vs map
-------------
1. object keys must be strings, where as map keys can be of any type.
2. we can get the size of a Map easily.  ex: map.size
   for object size has to be calculated manually. ex: Object.keys(obj).length
3.The iteration of maps is in insertion order of the elements
4.Objects are not inherently iterable (Object.keys() is slow), Maps are iterable.


Map
===
-Map is a collection that stores data in key-value format.
-Map Properties:
	Keys can be of any datatype
	Keys are unique
	Insertion Order is preserved
Why Do We need Map:
	When keys are not strings
	For Dynamic key-value data
	Faster 


 
 
 
 
Set
===
-A Set is a Javascript Object that stores unique values.
-Set can be iterated using loop,forEach()
-Set Properties:
	No Duplicate Values
	Maintains Insertion Order
	Can store any data type
	No indexing
-When To Use Set:
	Remove Duplicates easily
	Fast lookups (O(1))
