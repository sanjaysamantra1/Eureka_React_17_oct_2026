window methods
==============
alert : To Display Alert messages
        Message + Ok

confirm : User Confirmation        
          Message + Ok(true)  Cancel(false)

prompt : To Collect User input   
         Message + InputBox + Ok,cancel       




DataTypes
=========
-Primitives are immutable, non-primitives are mutable
-Primitives are compared by values, non-primitives are compared by address

Primitive : number, string, boolean, bigint, symbol
non-Primitive : Object
