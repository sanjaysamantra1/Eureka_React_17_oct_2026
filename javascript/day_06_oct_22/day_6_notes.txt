Function Declaration vs Function Expression
=============================================
1. Function Declarations are named, Function Expressions are not named (anonymous)
2. Function Declarations are Hoisted, Function Expressions are not hoisted



this keyword
============
-'this' is a keyword in javascript
-The value of this in JavaScript depends on how a function is invoked
-Arrow functions differ in their handling of this: they inherit this from the parent scope



How 'this' works with Regular function and arrow function
=========================================================
Regular : this - How the function is invoked 
Arrow : this - decided from the lexical scope (the scope where function is written)


Arrow Limitations
=================
-Arrow functions should not be used as objet methods
